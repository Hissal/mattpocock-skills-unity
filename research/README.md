# Research

One file per area of the Unity adaptation, each feeding the Unity skills and deltas it names at the top. Rules for keeping a file honest as findings change:

- **Versions and date.** Each subsection states the Unity versions (and the CLI or package versions it leaned on) and the date it was read or observed on, or inherits them from a file-level line it names.
- **Forward pointer.** A superseded paragraph stays, opening with a pointer to what replaces it: *Superseded by <section or file>: <which part is wrong>.*
- **Citations follow claims.** When the claim a citation backs changes, re-point the citation to a source for the new claim, or remove it.
