This fork versions on its own line. For releases of `mattpocock/skills` before the fork, and for what each upstream sync brought in, see [upstream's changelog](https://github.com/mattpocock/skills/blob/main/CHANGELOG.md).

## 1.0.0

### Major Changes

- [#64](https://github.com/Hissal/mattpocock-skills-unity/pull/64) [`81d95a1`](https://github.com/Hissal/mattpocock-skills-unity/commit/81d95a1caff6604844e1d443c3e9fe616d9450d3) Thanks [@Hissal](https://github.com/Hissal)! - First complete Unity adaptation. The `unity` router and seven Unity skills (`unity-verification`, `unity-assemblies`, `unity-serialization`, `unity-testing`, `unity-code-lifecycle`, `unity-prototyping`, `unity-debugging`) ship in the plugin, setup writes the Unity config, and `implement`, `tdd`, `diagnosing-bugs`, `code-review`, `resolving-merge-conflicts`, `prototype`, `to-tickets`, `to-spec`, `codebase-design` and `improve-codebase-architecture` each call the router from one Unity delta line, with every upstream line kept verbatim. Outside a Unity repo every skill behaves exactly as upstream's.
