First complete Unity adaptation. The `unity` router and seven Unity skills (`unity-verification`, `unity-assemblies`, `unity-serialization`, `unity-testing`, `unity-code-lifecycle`, `unity-prototyping`, `unity-debugging`) ship in the plugin, setup writes the Unity config, and `implement`, `tdd`, `diagnosing-bugs`, `code-review`, `resolving-merge-conflicts`, `prototype`, `to-tickets`, `to-spec`, `codebase-design` and `improve-codebase-architecture` each call the router from one Unity delta line, with every upstream line kept verbatim. Outside a Unity repo every skill behaves exactly as upstream's.
