The `unity` router gains a Unity docs step: for an API or Manual fact no Unity skill states, it reads the docs for the repo's Unity version through `unity docs --url` (Unity CLI 1.0.0-beta.11 or later), run from the project folder or given `--editor-version`, and fixes the page name on a 404. Without the CLI it builds the same version-matched URL by hand. `ask-matt`'s `/unity` line names it.
