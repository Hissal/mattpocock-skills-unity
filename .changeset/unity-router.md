Add the `unity/` bucket and the `unity` router: the one entry point skills call for Unity knowledge. It detects a Unity project or UPM package (at the root, by glob, or at the Unity config's recorded path), reads the Unity config or states the defaults it assumed, and routes a need to the Unity skills that answer it. `ask-matt` gains a Unity section.
